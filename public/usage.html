NexusClearance API

A self-hosted HTTP microservice for solving Cloudflare challenges, AWS WAF, and CAPTCHAs via a real patched Chromium browser.

Quick Start

Docker

docker run -d \
  -p 3000:3000 \
  --shm-size=2g \
  --cap-add=SYS_ADMIN \
  nexustechpro/clearance:latest

First Request

curl -X POST http://localhost:3000/bypass \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com","mode":"cloudflare"}'

Response

{
  "success": true,
  "data": {
    "cf_clearance": "abc123...",
    "userAgent": "Mozilla/5.0 ...",
    "cookies": [ { "name": "cf_clearance", "value": "abc123...", ... } ],
    "title": "Example Domain",
    "finalUrl": "https://example.com/",
    "solveMs": 4200,
    "mode": "cloudflare"
  }
}

FlareSolverr Migration

NexusClearance is a drop-in replacement for FlareSolverr v3.x. Change one setting in your tool (Prowlarr, Jackett, etc.):

# Before
FlareSolverr URL: http://flaresolverr:8191

# After — that's it
FlareSolverr URL: http://nexus-clearance:3000

The /v1 endpoint accepts identical request/response shapes including session management.

Actions Pipeline

15 action types executed sequentially: click, type, scroll, hover, select, keypress, wait, navigate, waitForSelector, waitForText, waitForURL, evaluate, evaluateAndReturn, screenshot, and resolve.

"actions": [
  { "type": "waitForSelector", "selector": "#login-btn" },
  { "type": "click", "selector": "#login-btn" },
  { "type": "type", "selector": "#email", "value": "user@example.com" },
  { "type": "wait", "ms": 500 },
  { "type": "evaluateAndReturn", "script": "return document.title", "name": "pageTitle" },
  { "type": "screenshot", "name": "after_login", "fullPage": false }
]

Visual AI & Canvas Solver: resolve

The resolve action provides universal, caller-driven visual puzzle solving. NexusClearance captures the target element, injects the base64 image into your custom HTTP request, calls your AI vision model (Google Gemini, OpenAI GPT-4o, Anthropic Claude, or a custom solver), parses the target coordinates, and executes a human-like Bezier mouse movement and click directly on the canvas.

Available Body Placeholders:

  • {{image}} — The raw base64-encoded PNG data of the target element.
  • {{w}} — The element's client width in CSS pixels.
  • {{h}} — The element's client height in CSS pixels.

Example 1: Google Gemini Flash Vision Solver

{
  "url": "https://example.com/login",
  "mode": "cloudflare",
  "sessionId": "user_session_1",
  "actions": [
    { "type": "waitForSelector", "selector": "canvas#captcha" },
    {
      "type": "resolve",
      "selector": "canvas#captcha",
      "request": {
        "url": "https://generativelanguage.googleapis.com/v1beta/models/gemini-3.6-flash:generateContent?key=YOUR_API_KEY",
        "method": "POST",
        "headers": { "Content-Type": "application/json" },
        "body": {
          "contents": [{
            "parts": [
              { "text": "Locate the target puzzle coordinates x and y within width {{w}} and height {{h}}. Output strictly JSON: {\"x\": number, \"y\": number}" },
              { "inline_data": { "mime_type": "image/png", "data": "{{image}}" } }
            ]
          }]
        }
      },
      "timeout": 25000
    },
    { "type": "wait", "ms": 1500 }
  ]
}

Example 2: OpenAI GPT-4o Vision Solver

{
  "url": "https://example.com/portal",
  "mode": "cloudflare",
  "actions": [
    {
      "type": "resolve",
      "selector": "canvas#captcha-box",
      "request": {
        "url": "https://api.openai.com/v1/chat/completions",
        "method": "POST",
        "headers": {
          "Content-Type": "application/json",
          "Authorization": "Bearer YOUR_OPENAI_KEY"
        },
        "body": {
          "model": "gpt-4o",
          "response_format": { "type": "json_object" },
          "messages": [{
            "role": "user",
            "content": [
              { "type": "text", "text": "Locate target coordinates x and y within width {{w}} and height {{h}}. Output strictly JSON: {\"x\": number, \"y\": number}" },
              { "type": "image_url", "image_url": { "url": "data:image/png;base64,{{image}}" } }
            ]
          }]
        }
      }
    }
  ]
}

Sessions & Persistent Browser Contexts

Persistent sessions allow multiple /bypass requests or direct page interactions to share the same isolated browser context and open page tab without re-initializing browser state or losing cookies. Every persistent session has a hard 5-minute auto-destroy TTL (300,000 ms) to guarantee system memory is always reclaimed.

GET/sessions
POST/session/destroy
POST/session/get
POST/session/post

Listing Active Sessions

// GET /sessions
// Response:
{
  "success": true,
  "data": [
    {
      "sessionId": "user_session_1",
      "createdAt": "2026-09-12T18:00:00.000Z",
      "expiresInMs": 240000
    }
  ]
}

Destroying Sessions

// Destroy a specific session immediately
POST /session/destroy
{ "sessionId": "user_session_1" }

// Or terminate all active sessions at once
POST /session/destroy
{ "sessionId": "all" }

Direct Session Navigation

// Navigate or submit forms within the session's active tab
POST /session/get  { "url": "https://example.com/dashboard", "sessionId": "user_session_1" }
POST /session/post { "url": "https://example.com/settings", "sessionId": "user_session_1", "fields": { "#email": "user@example.com" } }

Proxy Endpoints

GET/get-proxy?country=HK
POST/proxies/ban
POST/proxies/refresh

Proxy pool auto-refreshes every 5 minutes from ProxyScrape v4 (HK, KH, TW, KR, VN — elite anonymity, >80% uptime, <2000ms). New proxies start at score 3/5; banned after 3 failures.
