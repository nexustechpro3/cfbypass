Nexuscfbypass API

A self-hosted HTTP microservice for solving Cloudflare challenges, AWS WAF, and CAPTCHAs via a real patched Chromium browser.

Quick Start

Docker

docker run -d \
  -p 3000:3000 \
  --shm-size=2g \
  --cap-add=SYS_ADMIN \
  nexustechpro3/cfbypass:latest

First Request

curl -X POST http://localhost:3000/bypass \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com","mode":"cloudflare"}'

Response

{
  "success": true,
  "data": {
    "cf_cfbypass": "abc123...",
    "userAgent": "Mozilla/5.0 ...",
    "cookies": [ { "name": "cf_cfbypass", "value": "abc123...", ... } ],
    "title": "Example Domain",
    "finalUrl": "https://example.com/",
    "solveMs": 4200,
    "mode": "cloudflare"
  }
}

FlareSolverr Migration

Nexuscfbypass is a drop-in replacement for FlareSolverr v3.x. Change one setting in your tool (Prowlarr, Jackett, etc.):

# Before
FlareSolverr URL: http://flaresolverr:8191

# After — that's it
FlareSolverr URL: http://nexus-cfbypass:3000

The /v1 endpoint accepts identical request/response shapes including session management.

POST /bypass

Universal solver endpoint. Supports all 10 solver modes.

POST/bypass
Field Type Required Description
url string required Target URL to solve
mode string optional Solver mode (default: cloudflare)
siteKey string optional Required for turnstile-min
waitFor number optional ms to wait after solve (max 10000)
getPageSource boolean optional Include full HTML in response
useProxy boolean optional Use auto proxy from pool
proxy object optional Manual proxy: {host, port, protocol, username, password}
country string optional Proxy country filter: HK, KH, TW, KR, VN
setCookies array optional Inject cookies before navigation
intercept array optional Capture in-flight responses: [{url, type}]
actions array optional Actions pipeline (see below)
sessionId string optional Reuse named browser context
async boolean optional Fire-and-forget, returns jobId
webhook object optional POST result to URL when done: {url, method, headers}

Actions Pipeline

14 action types: click, type, scroll, hover, select, keypress, wait, navigate, waitForSelector, waitForText, waitForURL, evaluate, evaluateAndReturn, screenshot. 

"actions": [
  { "type": "click", "selector": "#login-btn" },
  { "type": "type", "selector": "#email", "value": "user@example.com" },
  { "type": "wait", "ms": 500 },
  { "type": "evaluateAndReturn", "script": "return document.title", "name": "pageTitle" },
  { "type": "screenshot", "name": "after_login", "fullPage": false }
]

POST /bypass/batch

POST/bypass/batch
{
  "requests": [
    { "url": "https://site1.com", "mode": "cloudflare" },
    { "url": "https://site2.com", "mode": "cf-cfbypass" }
  ]
}
// Response: { "success": true, "data": { "jobs": [{ "jobId": "uuid", "url": "..." }] } }

Proxy Endpoints

GET/get-proxy?country=HK
POST/proxies/ban
POST/proxies/refresh

Proxy pool auto-refreshes every 5 minutes from ProxyScrape v4 (HK, KH, TW, KR, VN — elite anonymity, >80% uptime, <2000ms). New proxies start at score 3/5; banned after 3 failures.

Environment Variables

Variable Default Description
PORT 3000 HTTP server port
TIMEOUT_MS 120000 Global solver timeout per request (ms)
BROWSER_LIMIT 20 Max concurrent browser contexts
CONTEXT_POOL_SIZE 1 Pre-warmed context pool size (need 2GB+ RAM to increase)
BATCH_LIMIT 10 Max requests per /bypass/batch
JOB_TTL_MS 300000 Job expiry time (ms)
MEMORY_LIMIT_MB 1024 Heap threshold for memory manager (MB)
GEMINI_KEYS Comma-separated Gemini API keys for hCaptcha fallback
HEADED false Run browser in headed (visible) mode
TRANSFORMERS_CACHE /tmp/whisper-cache Xenova/Transformers model cache path

Error Codes

Code HTTP When
NOT_READY 503 Browser not initialized yet
TOO_MANY 429 At BROWSER_LIMIT capacity
BAD_REQUEST 400 Invalid URL, missing required field, invalid mode
FAILED 500 Solver threw — challenge not solved, timeout, context crash
NOT_FOUND 404 Job ID not found, unknown route
NO_PROXY 503 Proxy pool empty or exhausted

Solver Comparison

Mode Speed What it solves Use when
cloudflare Medium Full CF bypass Need full cookie set + source
cf-cfbypass Fast CF cookie only Just need the cfbypass cookie
turnstile-min Fastest Turnstile token You have the siteKey, no live page needed
turnstile-max Medium Turnstile from live page Widget embedded in real CF page
waf-session Medium CF cookies + headers Need to replay via CycleTLS/curl
source Medium Page HTML after CF clears Scraping CF-protected content
hcaptcha Slow hCaptcha token Site uses hCaptcha (not CF)
recaptcha-v2 Slow reCAPTCHA v2 token Audio challenge approach
recaptcha-v3 Medium reCAPTCHA v3 token + score Behaviour-based, no visual challenge
aws-waf Medium AWS WAF token cookie Amazon/AWS-protected endpoints
